Prompt caching

  1. Every message resends the entire conversation, not just the new text.
  2. That growing history is cached as a document Claude re-reads instead of reprocessing.
  3. A cache write costs 2x base input price; a cache read costs 1/10th — a 20x swing.
  4. The cache expires after 1 hour of no activity, and refreshes on every message sent.
  5. Switching model, effort, MCPs, or compacting resets it early, mid-conversation.

What to do

  • Don't leave an important long conversation idle for over an hour if you intend to continue it — the next message pays full cache-write price for everything before it.
  • Avoid switching models, effort level, or MCPs mid-conversation if preserving the cache matters more than the change.
  • If you must step away for over an hour, decide in advance whether to /clear, /compact, or hand off — don't just come back and send the next message cold.

Clear, compact, or handoff

When a long conversation's cache is gone or about to be, the choice isn't whether to lose the history — it's whether nothing carries forward (/clear), a summary rides in the message history (/compact), or a summary lives as a file on disk (a handoff document).

Clear, compact, or handoff

  1. /clear wipes the conversation; the codebase itself carries the context forward.
  2. /compact summarises the conversation, then starts fresh with that summary injected.
  3. A handoff writes the summary to a markdown file on disk instead of into the message.
  4. The difference between compact and handoff is only where the summary lives.
  5. None of these beat staying under a few hundred thousand tokens in the first place.

Advisor mode

  1. A smart model plans the task; a cheaper model executes it.
  2. The executor only pulls the planner back in when it runs into trouble.

What to do

  • Route the planning step to your strongest model and the execution step to a cheaper one, rather than running one model through the whole task.
  • Let the executor escalate to the planner only when it's stuck — don't route every step through the strong model by default.

Timing beats trimming

A concise-output rule shaves output tokens, which are one line item. Prompt caching is the whole conversation's input cost, and it swings 20x on whether you sent your next message inside the hour or outside it — or whether you switched models, effort, or MCPs mid-session without meaning to. Protect the cache while you're using it, have a deliberate plan for when it's gone, and keep the expensive model out of steps a cheaper one can execute.
