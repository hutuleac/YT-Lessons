If we zoom into write file here, this is a tool which writes a file to the file system and it has two input parameters, a path which is a string and content which is also a string. and any other info that you've provided to the system prompt just goes below it. So there's nothing particularly fancy here going on. It's just tool definitions inside the system prompt. The magic happens when we ask the LLM to choose a tool. We've got our system prompt up here saying you have access to the following tools.
